# 史奴比的流量追蹤

蝦皮雙店舖（日井／文信）流量與產品競爭力儀表板。視覺採原創黑白漫畫小獵犬語彙，不包含受版權保護的角色素材。

## 資料更新架構

- Drive 資料夾分區：`1 日井`、`2 文信`。
- 每份檔案以 Drive ID、修改時間與 SHA-256 建立 checkpoint。
- 只處理新增或變更檔案，父商品摘要列避免重複計算規格資料。
- v1.1.1 已接入 2026/08/03—08/09 與 08/13—08/19 兩個區間。
- 前端只發布去識別化聚合資料，不公開買家個資或訂單編號。

## 安全與維護

- 原始 Excel 不提交到 repository。
- 每次發布前執行資料隔離、敏感資訊、頁籤與版本一致性測試。
- 版本採語意化版本，GitHub Actions 通過後才部署 Pages。
